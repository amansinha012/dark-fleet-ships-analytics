# 🚢 Maritime Dark Fleet Intelligence System

Python-based maritime anomaly detection and risk-scoring dashboard built with Pandas, NumPy, Seaborn, and Matplotlib.

## 📌 Key Features
- **Telemetry Simulation**: Generates Ships movement logs with speed anomalies.
- **Risk Scoring Engine**: Calculates risk profiles (0–100) based on velocity violations.
- **Geospatial Analytics**: Maps density hotspots using KDE heatmaps.

## 🛠️ Tech Stack
- Python, Pandas, NumPy, Matplotlib, Seaborn
